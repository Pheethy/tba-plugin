# /tba:design <KEY>

เข้า **Pre-Build Trial** — design session แบบ Q&A สำหรับการ์ด RTRCDS 1 ใบ จบแล้วได้ draft plan พร้อม post เข้า Jira

## Args
- `<KEY>` — Jira issue key (e.g. `RTRCDS-1234`)

## Steps

### 1. Load card context

```bash
node ${CLAUDE_PLUGIN_ROOT}/scripts/jira.mjs case <KEY>
```

เก็บ summary + description + AC ไว้เป็น context

### 2. Load relevant repo context (optional)

ถ้าใน current working directory มี `.tba/cache/` → อ่าน `project-map.md` มาประกอบ context
ถ้าไม่มี แต่มี `hc-my-career-docs/` ใน workspace → อ่าน `tba/system-map.md`

### 3. Invoke brainstorming skill

**Required:** ก่อนถามคำถาม ให้ invoke skill `superpowers:brainstorming` (หรือ `tb-brainstorming` ของ user ถ้ามี) ผ่าน Skill tool

ถ้าทั้งคู่ไม่มี → fallback เป็น structured Q&A ตามลำดับนี้ (ถาม**ทีละข้อ** รอคำตอบก่อนข้ามไป):

**Phase 1 — Clarify intent (1-2 คำถาม)**
- "เป้าหมายของ feature นี้คืออะไรจริง ๆ นอกจากที่เขียนใน AC?"
- "User persona หลักคือใคร? (employee / planner / admin / HR)"

**Phase 2 — Data model (ER)**
- "มี entity ใหม่/table ใหม่ไหม? ถ้ามี field อะไร ความสัมพันธ์ยังไง?"
- "กระทบ table เดิมใน DB ตัวไหน? ต้อง migration แบบไหน?"

**Phase 3 — API surface**
- "endpoint ใหม่/แก้มีอะไร? ใช้ repo ไหน (hc-my-career-api-*)?"
- "สัญญา request/response เป็นยังไง? auth/role ต้องอะไร?"

**Phase 4 — Flow (sequence)**
- "flow จาก user action → FE → BE → DB → response เป็นยังไง?"
- "มี async/cron/webhook เกี่ยวข้องไหม?"

**Phase 5 — Edge + risk**
- "edge case อะไรที่ต้องระวัง? (concurrent, duplicate, timezone, null)"
- "มี dependency กับ feature อื่นที่กำลังทำไหม?"

## Rules

- **ถาม Q&A จริง** อย่าเดา — การ์ด Jira มักมี context ที่ TBA ไม่เห็น
- **ไม่โพสต์อะไรเข้า Jira ใน command นี้** — แค่สร้าง draft เท่านั้น
- **Reuse brainstorming skill** ให้ได้มากที่สุด — มันออกแบบมาเพื่อ clarify intent + explore design โดยเฉพาะ
- Diagram เป็น mermaid เสมอ (GitLab/Jira preview ได้)
- ถ้า user ขอ "ข้าม Q&A" → generate draft ตาม AC ล้วน ๆ แล้วใส่ `**TODO (ไม่ได้ confirm กับ user):**` ไว้ทุกจุดที่เดา

## Theme

- เริ่ม session ด้วย stamp: `[⌛ PRE-BUILD TRIAL CONVENED]`
- จบด้วย stamp: `[◉ TRIAL DRAFT READY]`
- ถ้า user abort: `[✂ TRIAL ADJOURNED]`
