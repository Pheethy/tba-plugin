# /tba:scan [path]

สแกน git-tracked files ใน repo ปัจจุบัน (หรือ path ที่ระบุ) → excerpt + คำสั่งสร้าง `project-map.md`

## Args
- `[path]` — absolute path; default = CWD
- `--multi` — scan all child repos under given path (ใช้สำหรับ workspace folder เช่น `my-career/`)

> **Auto-detect:** ถ้า CWD ไม่ใช่ git repo แต่มี child repos (เช่นอยู่ที่ `my-career/` ซึ่งข้างในมี 7 microservices) → TBA switch เป็น `--multi` ให้อัตโนมัติ, ไม่ต้องใส่ flag เอง

## Steps

### 1. Run scanner (duck animation)

```bash
node ${CLAUDE_PLUGIN_ROOT}/scripts/scan.mjs [path] [--multi]
```

เป็ด Scout จะ walk ไฟล์ให้ดู output ลงที่ `<repo>/.tba/cache/scan.json`

### 2. Read scan result

```bash
cat <repo>/.tba/cache/scan.json
```

### 3. Compose project map

จาก excerpts + file list → เขียน **project map markdown** ลงที่ `<repo>/.tba/project-map.md`:

```markdown
# <repo-name> — Project Map

> Generated by TBA on <timestamp>
> Scanned <N> files · <M> excerpts

## Overview
<2-3 ประโยคสรุป ว่า repo นี้ทำอะไร, stack อะไร, role ใน hc-my-career ecosystem>

## Entry Points
- `path/to/main.go` — ...
- `path/to/server.ts` — ...

## Architecture
\`\`\`mermaid
graph TD
  ...
\`\`\`

## Components
### API Layer
- `handlers/...`
### Business Logic
- `service/...`
### Data Access
- `repository/...`

## External Dependencies
- Database: ...
- Message queues: ...
- Other services: ...

## Key Flows
<describe 1-2 main request flows>

## Open Questions / Gaps
<things the scan couldn't determine>
```

**Rules for composition:**
- **Cite paths** จาก excerpts (ให้ dev ตรวจได้)
- **Distinguish fact vs assumption** — ถ้าเดา → ขึ้นต้น "assumption:"
- **Never reproduce secrets** — ถ้าเจอ env var pattern ให้บอก variable name เฉย ๆ
- **Diagram เป็น mermaid** — หลีกเลี่ยง ASCII art
- **ยาวไม่เกิน ~20KB** — ถ้าซับซ้อนมากให้บอก "see guides/" แล้วแนะนำให้ split

### 4. Present summary

```
[◎ TIMELINE SWEEP COMPLETE]

  Repo:         <name>
  Scanned:      <N> files
  Excerpts:     <M> files (~<bytes>)
  Map saved:    .tba/project-map.md

  Next:
    cat .tba/project-map.md     → review the map
    /tba:design <KEY>           → use this context for a trial
```

## Notes

- Scan **ข้าม hidden folders, node_modules, vendor, build, secrets** โดย default (ดู `EXCLUDED` regex ใน `scan.mjs`)
- ถ้า repo ใหญ่มาก (>120 candidate files) → จะเอาแค่ 120 ไฟล์แรก sorted by priority (README/manifest > source > config)
- Excerpt ตัดที่ ~2.2KB ต่อไฟล์, รวม <10KB (ป้องกัน context balloon)
- Cache stale? → แค่ `/tba:scan` ซ้ำ → overwrite
